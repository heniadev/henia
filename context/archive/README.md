# context/archive/

Completed changes, moved here from `context/changes/` by `/101-archive`.

This directory is **read-only by convention**. Archived changes are a
historical record: they are not edited, re-planned, or reopened in place.

The 101 skills refuse to write here (G-14). If a resolved target path
starts with `context/archive/`, the skill aborts and points at `/101-new`
to open a fresh change instead.
